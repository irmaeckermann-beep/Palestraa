# Palestraa — Vetrina Fitness

Sito vetrina per una palestra, generato con Stitch nello stile **"Velocity Brutalism"** (dark, rosso/nero, tipografia massiccia).

## Struttura

- [index.html](index.html) — la pagina principale (Tailwind via CDN, single file)
- [DESIGN.md](DESIGN.md) — il design system di riferimento
- [docs/screen.png](docs/screen.png) — screenshot del design originale

## Sviluppo locale

Basta aprire `index.html` nel browser, oppure:

```bash
python3 -m http.server 8000
```

e visitare http://localhost:8000
